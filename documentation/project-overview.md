# Documentación de PetGrow

## Descripción general

PetGrow es una aplicación web orientada al cuidado integral
de las mascotas.

## Funcionalidades propuestas

- Registro del perfil de cada mascota.
- Orientación sobre alimentación e hidratación.
- Seguimiento de hábitos y actividad física.
- Calendario de salud preventiva.
- Recordatorios de cuidados.
- Registro de cambios en el desarrollo de la mascota.

## Estado actual

El proyecto se encuentra en la fase de planificación inicial.
