# PetGrow

## 1. Nombre del proyecto

PetGrow: Aplicación para el cuidado y desarrollo integral de mascotas.

## 2. Descripción del proyecto

PetGrow es una aplicación web diseñada para ayudar a los propietarios
a cuidar de sus mascotas mediante herramientas de seguimiento y
recomendaciones sobre alimentación, hidratación, hábitos saludables,
actividad física, entrenamiento y prevención de enfermedades.

La aplicación busca facilitar el cuidado responsable de las mascotas
mediante información organizada y funciones adaptadas a sus
características y necesidades.

## 3. Objetivo del proyecto

Desarrollar una aplicación web que facilite el cuidado integral de
las mascotas, ofreciendo herramientas para organizar sus rutinas,
consultar información preventiva, registrar aspectos importantes
de su desarrollo y recibir recordatorios relacionados con su cuidado.

## 4. Herramientas utilizadas

- GitHub: almacenamiento y control de versiones del proyecto.
- GitHub Projects: organización y seguimiento de las tareas.
- Visual Studio Code: entorno de desarrollo.
- HTML: estructura de la aplicación web.
- CSS: diseño y presentación de la interfaz.
- JavaScript: implementación de funcionalidades interactivas.
- Draw.io: elaboración de diagramas y diseños del sistema.

## 6. Estado inicial del proyecto

El proyecto se encuentra en su fase inicial de planificación
y organización. Se está preparando el repositorio, la documentación,
la estructura de carpetas y la lista de tareas necesarias para
iniciar el desarrollo de la aplicación.

## 7. Organización del trabajo

El trabajo se organizará utilizando GitHub Projects para visualizar
y controlar el progreso de las tareas.

Las actividades se registrarán mediante issues, que incluirán
un título claro, una descripción y una etiqueta.

El tablero de trabajo utilizará los siguientes estados:

- Pendiente.
- En proceso.
- En revisión.
- Completado.

El proyecto se desarrollará de forma progresiva, comenzando por
la planificación y documentación, continuando con el diseño de
la interfaz y posteriormente con la implementación y revisión
de las funcionalidades.
